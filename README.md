One ripe mango does all the work here: a hedgehog-cut cheek in front, its glossy orange cubes pushed up and catching warm light from the top-left, with a whole mango resting behind it and green leaves tucked at the base, all on a deep teal backdrop that makes the gold flesh glow. The program is a small hand-rolled rasteriser in pure Python standard library — gradients, ellipses, polygons and blended highlights drawn into a framebuffer, then encoded as a PNG with zlib. No text, no assets, just drawn fruit.

## Run it

```
python3 main.py
```
